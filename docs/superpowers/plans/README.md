# Historical Implementation Plans

This directory is an archive of implementation plans used to build AGPair 1.0.
These files are not the current user-facing behavior contract.

For current behavior, use:

- `README.md`
- `docs/getting-started.en.md`
- `docs/usage.md`
- `docs/executor-lifecycle.md`
- `skills/Codex/SKILL.md`
- `skills/Claude/SKILL.md`

Older plans may mention retired or legacy paths such as Gemini, Antigravity IDE,
or bridge-based execution because they preserve historical decision context.
New code, docs, and agent routing must follow the current behavior documents
above.

The current product version is AGPair 1.0. Old plan filenames keep their
original version labels because they are historical evidence, not release
metadata.
